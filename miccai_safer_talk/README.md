# MICCAI 2026 SAFER talk and poster

Oral Presentation 1, Sunday 27 Sep 2026, 08:15–09:15 CEST, Room Curie B, Strasbourg. Poster session 12:30–13:30 the same day. MICCAI 2026 is in-person only; workshop organisers may ask for the slides in advance.

- `talk_16x9.pptx`: 12-slide talk deck, 16:9, figures embedded, script in the speaker notes. `talk_16x9.pdf` is the PDF export.
- `talk_script.md`: the 12-minute script with per-slide timings and Q&A prep.
- `poster_A0.pptx`: portrait A0 (841 x 1189 mm) poster. `poster_A0.pdf` is print-ready. Import the PPTX into Canva via Create > Import file.
- `build_deck.js`, `build_poster.js`: generators. Rebuild with `node build_<x>.js` from a directory that has `pptxgenjs` installed; edit numbers or text there, not in PowerPoint.
- `paper.pdf`: camera-ready. `pdf_images/`: figures extracted from it plus the repo QR code.
